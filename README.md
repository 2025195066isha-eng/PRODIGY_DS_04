# PRODIGY_DS_04

## Sentiment Analysis & Data Visualization

This repository contains a Python project created for **Prodigy InfoTech - Task 04**. It analyzes and visualizes sentiment patterns in social media (Twitter) data to understand public opinion and attitudes toward specific topics or brands.

## Features
- **Dataset Integration**: Downloads Twitter training data directly from the official Prodigy InfoTech dataset repository.
- **Sentiment Scoring**: Utilizes NLTK's VADER (Valence Aware Dictionary and sEntiment Reasoner) Lexicon to classify text into `Positive`, `Neutral`, and `Negative` sentiments.
- **Data Visualization**: Generates distribution plots using `Seaborn` and `Matplotlib` to show overall sentiment spread and entity/brand sentiment breakdown.
